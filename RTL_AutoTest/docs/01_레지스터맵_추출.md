# 1단계 — 레지스터 정의 헤더 → 레지스터맵, 사양서와 대조

> 입력: 0단계 재원 중 '레지스터 정의 헤더(01_input/testvector/*_regmap.vh)', '사양서', '현장 지식(엔디안)'

테스트벡터 RTL은 `ADDR_H_ACTIVE` 같은 기호로 레지스터를 가리킨다. 이 기호를 실제 주소·폭·접근 권한으로 바꾸려면 레지스터맵이 필요하다.

## AI 작업
- 헤더의 `localparam ADDR_<이름> = 7'hXX; // REG width=.. access=.. reset=.. rw_mask=..` 를 읽는 추출 코드 초안 (tool/core/rtl_parser.py)

## 프롬프트
```
아래 Verilog 헤더에서 레지스터 목록을 뽑는 Python 함수를 작성해줘.
- 주소: localparam ADDR_<이름> = 7'hXX;
- 속성: 같은 줄 주석 "// REG width=.. access=.. reset=.. rw_mask=.. desc=.."
- I2C 장치 주소: localparam I2C_DEV_ADDR = 7'hXX;
규칙: 속성 주석이 없으면 값을 추측하지 말고, 빠진 속성 이름을 경고로 돌려줘.
<헤더 붙여넣기>
```

## 사람이 확인한 것
| 항목 | 확인 방법 |
|---|---|
| 레지스터 13개 | 추출 표를 사양서 4장 표와 1:1 대조 (주소·폭·접근·리셋값·rw_mask) |
| 바이트 순서 | 사양서 기재값(big)을 기본으로. IP마다 다를 수 있다는 현장 지식 → 툴에서 big/little 선택 가능하게 |
| IP별 차이 | VDDI-200은 CHIP_ID, I2C 주소가 다름 → IP 디렉토리마다 regmap.yaml 별도 저장 |
