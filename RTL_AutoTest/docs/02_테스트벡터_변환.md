# 2·3단계 — 테스트벡터 RTL → SPI / I2C 포맷 변환 (툴 본 기능)

> 입력: 테스트벡터 RTL(01_input/testvector/tv_*.v) + 1단계 레지스터맵 + SPI·I2C 프레임 형식(사양서 3장)

## 테스트벡터 RTL 형식
```verilog
// @test T03 RW 패턴 쓰기/읽기
chip_reset;
reg_write(ADDR_H_ACTIVE, 16'h0040);
reg_read (ADDR_H_ACTIVE, 16'h0040, 16'h07FF);   // 주석 = 항목 이름
frame_check("colorbar");                         // 화면 비교 (데모 DUT 전용)
```
실제 Verilog로도 컴파일된다 (tv_tasks.vh).

## AI 작업
- 테스트벡터 RTL 파서 초안 (tool/core/tv_parser.py)
- SPI / I2C 인코더 초안 (tool/core/vector_spi.py, vector_i2c.py)

## 프롬프트
```
Verilog 테스트벡터에서 chip_reset / reg_write(addr, data) / reg_read(addr, exp, mask) / frame_check("name")
문장을 읽어 레지스터 단위 동작 리스트로 바꾸는 Python 모듈을 작성해줘.
- addr 는 ADDR_<이름> 기호 또는 숫자. 레지스터맵으로 폭을 찾는다.
- 숫자는 Verilog 표기(16'h0040, 8'b1010, 96)를 해석.
- 각 동작에 원래 파일:줄을 남겨라 (변환 결과를 RTL로 거슬러 찾기 위해).
- 해석하지 못한 줄, 없는 레지스터, 폭보다 큰 값은 추측하지 말고 경고로 돌려줘.
그 다음, 동작을 바이트 순서에 따라 바이트로 펼쳐
- SPI : 16비트 프레임 [R/W | ADDR(7) | DATA(8)], 읽기는 MISO 기대값·마스크 포함
- I2C : S | DEV+W | A | REG | A | DATA | A | P / 읽기는 Sr 후 DEV+R, 마지막 NA
형식으로 출력해줘.
```

## 사람이 확인한 것
- RTL 한 줄 ↔ 변환 줄 대응을 GUI에서 클릭으로 확인 (16비트 쓰기 1줄 → SPI 2줄)
- 변환 결과 몇 줄을 사양서 3장 프레임 형식과 직접 대조
- 일부러 틀린 테스트벡터(없는 레지스터, 잘못된 문법, 큰 값)를 넣어 경고가 나는지 확인
