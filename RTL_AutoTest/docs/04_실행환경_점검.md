# 4단계 — 실행 환경 점검 (다른 사람 PC에서도 돌아가게)

## 문제
- PC마다 Python 버전·설치 패키지가 달라, 내 PC에서 되는 스크립트가 다른 PC에서 안 됨

## 입력
- 필요 패키지 목록(requirements.txt), 지원 Python 버전, 필수 파일 목록

## AI 역할
- 점검 스크립트 초안 (버전 확인, 패키지 확인·설치, 결과 저장)

## 사람이 정한 것
| 항목 | 기준 |
|---|---|
| Python 버전 | 3.9 이상, 3.9~3.13 검증 |
| 스크립트 호환성 | 프로젝트의 모든 .py 를 현재 Python으로 컴파일해서 문법 오류 확인 |
| 패키지 | 없거나 버전 낮으면 **설치 전에 사용자에게 물어봄** (임의 설치 안 함) |
| 시뮬레이터 없음 | 실행을 막지 않고 Python 모델로 대체 |

## 확인
- 패키지가 없는 새 Python 3.11 환경에서 실행 → 누락 감지 → 설치 → 정상 실행 확인
